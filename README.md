# Medical Directory Scraper — jameda.de

A Python web scraping project that extracts healthcare provider information from public medical directory pages and exports clean structured data for review.

## What it does

- Extracts provider names, specialties, addresses, ratings, review counts and contact fields
- Handles paginated listing pages
- Translates German specialty names into English
- Parses address fields into cleaner components
- Exports results into CSV and Excel formats
- Uses request delays and logging to support responsible scraping

## Tools used

- Python
- BeautifulSoup
- requests
- pandas
- openpyxl
- deep-translator

## Output fields

- Full Name
- Specialty German
- Specialty English
- Street
- House Number
- City
- Postcode
- Country
- Phone
- Rating
- Review Count
- Scraped At

## Why this project matters

This project demonstrates practical web scraping, structured data extraction, healthcare directory parsing, data cleaning and QA review. It is relevant to data operations, AI-assisted workflows, and web extraction roles that require accurate structured outputs.

## Notes
